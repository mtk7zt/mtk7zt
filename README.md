## 🚧 Currently Building

### ValuTrail

**Deterministic portfolio valuation and market-event replay in Java.**

ValuTrail explores how an ordered history of market events can be used to reconstruct portfolio valuation and P&L with an emphasis on **reproducibility, validation, and traceability**.

Current engineering work includes deterministic replay, idempotent event handling, conflict detection, scenario analysis, automated testing, CI, and documented market-data provenance.

**Current:** 4-event verified replay  
**Goal:** Progressively challenge the architecture toward 1,000,000+ events, persistence, checkpointing, recovery, and replay verification.
